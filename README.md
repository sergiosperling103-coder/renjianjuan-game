# 人间卷 · 一生传记

一部长篇传记的生成式叙事网页游戏：从第一声啼哭到最后一息落墨，你亲手为自己的命运铺路。

## 运行方式

无需安装任何东西。双击 `index.html`，用 Chrome / Edge 等现代浏览器打开即可游玩。

## 玩法

1. **第一章 · 命运的原点**：依次回答四个问题——姓名与性别、出生年月日、出生地点、最初的屋檐。父母与手足的姓名由系统按时代用字土壤自动生成。
2. **第二章 · 灵魂的质地**：从四张「容颜底色 × 灵魂初胚」的草图里，亲手涂上命运长卷的第一层底色。
3. **天赋抽卡**：命运发十张牌（常见 / 稀有 / 传说），选一至两张入世；再把三枚初始点数亲手分配。
4. **正文**：时间流动，人生分幕展开。每个十字路口都有具体、可感、导向不同命运的选项，标注风险等级（平静 / 微澜 / 暗流 / 深渊）；也可以跳出选项，以你自己的话作答。
5. **四道金线**：爱情、友情、亲情、事业相互撕扯与承接，侧栏实时显示十一项属性（心境、气运、洞察、守心）、天赋、亲人羁绊与命运烙印。
6. **心境与决堤**：心境跌破临界，情绪会强制在场——「决堤之夜」不可跳过，只能一步步走过。
7. **无常法则**：微小选择可能在多年后引爆；气运高低会影响意外坍缩与平行命运揭示的概率。
8. **时间回溯**：可退回最近一次抉择之前，但代价是消融一段高浓度记忆，并轻微改变他人轨迹。
9. **成就与结局图鉴**：一生可解锁二十余枚勋章；终章给出结局称号（白首偕老、孤舟独行、时代弄潮……）、雷达图与四项结算。
10. **人性的险恶**：约二十个暗面事件——嫁祸、霸凌、代考陷阱、背锅、撬墙角、杀猪盘、保健品骗局、争产、网暴、伪善……真相可能迟到数年才揭晓。高「洞察」才能看穿陷阱，低「守心」会滑向更恶的选项；被辜负的创伤会留在烙印里。
11. **暗面档案**：命运档案新增分页，盘点你这一生撞见过多少次人性之恶、守住多少底线。
12. **轮回继承**：每一世临终都会留下「遗愿」，下一世开局注入对应的属性加成。
13. **终章**：强制日模式，走马灯重现一生；给出情感密度、自我实现、遗憾指数、时代印记四项结算、人性盘点，以及悼词、最后一束花、遗留之物与话语余波。

## 附加功能

- 流速切换（年 / 月 / 日）：年模式掠过漫长岁月，日模式细观一日光影。
- 打字机叙事：正文逐字浮现，点击正文可快进；快捷键 1~4 选选项、Enter 继续、Esc 关弹层。
- 自动存档：侧栏「存档」手动落印；首页可「继续前尘」读取。
- 命运档案：时间线 / 记忆碎片 / 成就图鉴三个分页。
- 设置面板：打字速度、氛围音、自动存档开关，以及存档导出 / 导入（换设备不丢命）。
- 氛围音：右下角「音」字按钮可开关。


全部为本地静态文件，不依赖网络。
